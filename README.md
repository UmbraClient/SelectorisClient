SelectorisClient — это клиент для Minecraft Windows 10 Edition v1.1.5. Будет 2 версии: одна с читами, вторая без читов. В данный момент доступна только версия без читов.

Весь функционал описан ниже. Со временем он будет улучшаться, функции дорабатываться и добавляться новые. Например, такие функции как MotionBlur, Trajectories и прочие визуалы, а также взаимодействия с миром будут улучшаться со временем.

Функционал:
Movement
    NoHurtCam — отключает тряску камеры при получении урона
    ItemDelayFix — исправляет задержки при использовании предметов
    JavaHotkeys — позволяет быстро перемещать предметы из инвентаря в нужные слоты хотбара, как в Java-версии.
    QuickSlots — быстрый доступ к слотам инвентаря
    NoDynamicFov — отключает динамическое изменение FOV при спринте/атаке
    AutoSprint — автоматический спринт
    DiagonalSprint — позволяет спринтовать по диагонали
    TargetInfo — отображает информацию о цели (Ник, дистанцию, (будет дорабатываться))
    AspectRatio — настройка соотношения сторон экрана
    NoCamReset — камера не сбрасывается после смерти или телепортации
    Zoom — приближение камеры

Player:
    SensMultiplier — множитель чувствительности мыши
    CustomNames — кастомизация отображаемых имён игроков (будет дорабатываться)
    SelfNameTag — отображение собственного никнейма над головой
    SwingAnimations — анимации взмаха рукой
    Trajectories — отображение траектории полёта эндер перлов, полета стрелы т.п (будет дорабатываться)
    ViewModel — настройка положения предметов в руке
    JavaFov — FOV как в Java-версии

Misc:
    ArrayList — список активных модулей на экране
    Notifications — система уведомлений о событиях
    Watermark — водяной знак с названием клиента
    FpsCounter — отображение FPS
    ClickGuiModule — графический интерфейс для настройки модулей
    CpsCounter — счётчик кликов в секунду (CPS)
    Coordinates — отображение координат игрока (X, Y, Z)
    HitDistance — отображение расстояния удара до цели
    Keystrokes — отображение нажатых клавиш (WASD, мышь)
    PotCounter — счётчик зелий в инвентаре
    NoVSync — отключение вертикальной синхронизации для повышения FPS
    PackSwitcher — быстрая смена ресурспаков

Render:
    Snow — эффект снега (будут добавляться больше визуалов)
    Nimb — нибм над головой
    ChinaHat — декоративный эффект на голове игрока (будет дорабатываться)
    Trails — след (линия или точки) за игроком (будут добавляться больше визуалов)
    ESP — подсветка игроков и мобов через стены
    ItemInfo — информация о предмете в руке (Название, ид, количество, зачарование) (будет дорабатываться)
    NoRender — отключение рендеринга объектов (облака, частицы, туман, брони т.д)
    MotionBlur — размытие движения (будет дорабатываться)
    JumpCircles — отображение кругов при прыжке (будут добавляться больше визуалов)
    HurtColor — изменение цвета экрана при получении урона (будет дорабатываться)

World:
    ChunkBorder — отображение границ чанков
    FogColor — изменение цвета тумана
    FullBright — полная яркость
    Skybox — кастомизация неба
    ItemPhysics — физика для выброшенных предметов
